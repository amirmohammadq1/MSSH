# مستند صوتی شنود

## فایل‌هایی که خودتان باید اضافه کنید قبل از بیلد

لوگو از قبل اضافه شده (`assets/logo.png`). فقط فایل‌های صوتی (mp3) باقی مانده‌اند — دقیقاً با همین نام‌ها در مسیر `assets/audio/` قرار دهید:

**فصل یک (۱۶ فایل):**
```
mostanad_soti_shonud_part1.mp3
mostanad_soti_shonud_part2.mp3
mostanad_soti_shonud_part3.mp3
...
mostanad_soti_shonud_part16.mp3
```

**فصل دوم (۲ فایل):**
```
mostanad_soti_shonud_s2_part1.mp3
mostanad_soti_shonud_s2_part2.mp3
```

همه‌ی این ۱۸ نام از قبل توی `pubspec.yaml` (بخش assets) نوشته شده‌اند؛ کافی است خود فایل‌ها را با همین اسم‌ها در پوشه بگذارید — نیازی به تغییر کد نیست.

## حجم برنامه
با توجه به این‌که حدود ۳۰۰ مگابایت فایل صوتی اضافه می‌کنید و برنامه خودش (بدون صدا) چند مگابایت بیشتر نیست، حجم نهایی APK باید در همان محدوده‌ی ۳۰۰ تا ۳۶۰ مگابایتی که مدنظرتان بود باقی بماند.

## حدیث‌های خالی
برای قسمت‌های ۸، ۱۴، ۱۵ و ۱۶ (فصل یک) و قسمت ۲ فصل دوم، طبق خواسته‌ی شما هیچ حدیثی گذاشته نشده و صفحه‌ی «حدیث‌های مرتبط» برایشان فقط با سربرگ خالی باز می‌شود.

## ویرایش‌های اعمال‌شده روی متن حدیث‌ها
- قسمت ۲ (حدیث نیت): تناقض متن عربی اصلی رفع شد؛ توضیح این اصلاح به‌صورت یک یادداشت کوچک زیر همان حدیث در برنامه نمایش داده می‌شود.
- قسمت ۲ (حدیث نجات انسان): چون نقل‌قول ناقص بود، در پایان متن عربی و فارسی «...» اضافه شد تا مشخص باشد ادامه دارد.
- قسمت ۱۳: شماره‌ها و منبع یکدست شدند و یک یادداشت توضیحی کوتاه زیرش اضافه شد.

## امضا برای انتشار در مایکت
دقیقاً مثل پروژه‌های قبلی، با تنظیم Secret های زیر در گیت‌هاب، ورک‌فلو به‌صورت خودکار apk امضاشده تولید می‌کند: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
